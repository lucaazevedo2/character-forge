# Magic items beta — 0.19.0-beta.1

Sites beta only. Release changelog will be consolidated when Luca requests production.

- 912 Wikidot index records, including separate rarity records where a named item spans tiers. Unknown/Unique retain their source labels.
- Global Item Explorer and shop rarity, source, and setting filters.
- Magic items have no price or cart path. Each addition, including increasing an inventory stack, needs a rarity-aware confirmation.
- White/green/cyan/purple/gold rarity colors; teal/magenta gradient artifacts. Colors appear in explorer, shop, confirmation, and inventory.
- Links to source rules and attunement requirement metadata. Owning an item does not automatically apply bonuses, charges, or attunement effects.
- Confirmed explorer and shop acquisition, cancel, inventory persistence, unchanged currency, and cart protections.
